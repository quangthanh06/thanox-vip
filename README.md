## 🚀 Hướng dẫn triển khai Online (Vercel / GitHub Pages)

### Cách 1: Đưa lên Vercel (Khuyên dùng - 1 phút)
1. Đăng nhập [vercel.com](https://vercel.com).
2. Nhấn **Add New Project** -> Chọn GitHub Repository này.
3. Nhấn **Deploy**.
4. Lấy tên miền Vercel (ví dụ `https://thanox-vip.vercel.app`) điền vào thẻ `<key>URL</key>` trong file `Thanox.mobileconfig`.

### Cách 2: Bật GitHub Pages
1. Vào mục **Settings** của repository này trên GitHub.
2. Chọn **Pages** -> Tại nhánh chọn **main** -> Thư mục chọn **/ (root)**.
3. Nhấn **Save**. Bạn sẽ có link web miễn phí chạy 24/7!

## 📱 Cài đặt lên iPhone bằng `Thanox.mobileconfig`

1. Gửi file `Thanox.mobileconfig` qua Telegram/Zalo/iCloud hoặc mở bằng **Safari**.
2. Khi có thông báo *"Đã tải về hồ sơ"* -> Vào **Cài đặt (Settings)** trên iPhone.
3. Nhấn vào mục **Hồ sơ đã tải về** -> Nhấn **Cài đặt (Install)** góc trên bên phải.
4. Nhập mật mã mở khóa máy -> Xác nhận cài đặt.
5. Icon **Thanox VIP** sẽ xuất hiện ngay trên Màn hình chính!
